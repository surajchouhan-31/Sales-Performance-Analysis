# Sales Performance Analysis

## Overview
This project focuses on analyzing sales data using Power BI to identify business trends, regional performance, profit insights, and sales growth patterns.

The dashboard provides interactive visualizations that help understand overall business performance and support data-driven decision making.

---

## Tools Used
- Power BI
- Microsoft Excel / CSV Dataset

---

## Features
- Sales trend analysis
- Region-wise sales performance
- Profit analysis
- Category and sub-category insights
- Interactive dashboard visuals
- KPI tracking

---

## Dashboard Insights
The dashboard helps in:
- Identifying top-performing regions
- Tracking sales and profit trends
- Understanding category-wise performance
- Monitoring key business metrics
